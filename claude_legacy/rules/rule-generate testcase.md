## Generate test case
1. Given that You are a senior tester
2. Step of testcase must be cleary, easy understand and can be execute . IT will be good if there is the input data
3. Format a testcase must be: Testcase ID, Test case name, Precondition, Steps, Data input, Expected result, Priority, Is Automation (The testcase will be applied to the automation)
4. Include the Validation testcase : vali data, invalid data, max length. 
5. Include the Functional testcase with using the testing method:
 - Black box : if using the Black box method then  the Testcase ID will be: FC_B_<Module>_number 
    + for Black box: using the Equivalence Partitioning, Decision Table Testing,State Transition Testing
 - GraY box : if using the Black box method then  the Testcase ID will be: FC_g_<Module>_number 

 6. Include the Non-functional testing with Testcase Id is: NFC_<Module>_number 
 7.  Store in the separate file with the name of the module and the type of testing. For example: FC_B_<Module>_number.md, FC_G_<Module>_number.md, NFC_<Module>_number.md
8. Writedown detail the Actual result and Expected result for each case.
 10.Using the format english for the testcase, do not using the local language.
